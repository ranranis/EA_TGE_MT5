# 当前项目 Skill 来源说明

`Experts/.codex/skills` 是本项目纳入版本管理的 Skill 来源。

- `ea-trade-manager-v156` 是本项目 EA v1.56 的专用 Skill。
- `mql5-ea-maintainer`、`mql5-trade-lifecycle-auditor` 和 `mql5-compile-reviewer` 是当前项目使用的通用 MQL5 Skill。
- 上层 `MQL5/.codex/skills` 可能存在同名的环境级副本。它们不属于当前项目的维护来源；本项目修改和审查以本目录的版本为准。
- 如果同名副本内容不一致，应先更新本目录版本，再决定是否同步环境级副本；不要反向从环境副本覆盖项目 Skill。
