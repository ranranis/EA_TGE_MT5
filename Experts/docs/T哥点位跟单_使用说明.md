## 1.61 持单策略下拉选择

EA属性 → 输入参数 → “持单策略 · 切换只影响新开仓” → “持单策略”：

|选项|行为|
|---|---|
|固定TP5 / SL10|按实际成交均价设5价格距离的全量TP、10价格距离的SL；不分批、不主动移保本、不做结构或时间退出。此模式不采用老师的SL/TP覆盖，也不受下面的保险/首批/尾仓距离参数影响；已经存在的更紧SL保留。|
|旧版分批|恢复原触价与退出链路，默认保险10、到5后按K线判断分批/全平、尾仓默认10，保留老师明确退出价覆盖。|
|新版结构（默认）|使用下文1.60的积极入场、分级保护、结构退出。|

三个选项选择整套策略：新增的消息窗口、冲击冷却、逆势M1确认、区域亏损重试和合计风险过滤只用于新版结构的新开仓。固定与旧版仍保留基础点差、短窗逆向冲击、来源有效性等原有检查；它们不会获得新版的日历保护。已成交的新结构仓仍按自己的规则管理。

模式在发请求前保存，真实成交后绑定POSITION_IDENTIFIER。切换下拉选项不会改造已有仓位；重新挂载也不会把旧单当成新模式单。面板底部显示新开仓所选模式，固定仓的持仓进度明确标注“固定TP5 / SL10”。本版以该下拉框替代1.60的“启用积极持单”布尔输入；导入旧set时请核对下拉框，缺失该字段时默认新版结构。

## 1.60 积极入场、分级保护、结构化退出

本节为当前新增交易规则。下文保留早期版本说明作历史记录；早期的入场、过滤和退出描述不代表1.60的当前默认规则。

重新挂载 Experts 根目录的 `EA_T哥点位跟单.ex5` 生效，不需要重启飞书监控。固定每单0.02手，原有点位优先级、来源检查、触价范围及请求对账继续生效。新增参数在“积极持单”和“消息保护”分组。

|环节|默认行为|
|---|---|
|正常入场|保留±1点位区域快速触价；不强制每单等待K线。|
|确认入场|M5 EMA20/50及EMA20斜率判定的逆势、最近一次亏损后的重试、消息/冲击恢复期，需完整M1触及区域、顺向收回点位，实体至少0.1倍M1 ATR。|
|区域重试|同区域（参考点位相差不超过2）已有本EA持仓时不叠加；同方向首次亏损后允许确认重试，连续亏损两笔后该区域冷却30分钟。其他区域独立。按最近7天真实完整平仓净结果计算，费用计入，盈利或持平重置。旧策略单不进入新策略重试统计。|
|初始止损|取最近3根完整M1结构和点位外沿，另留0.25 ATR、点差、2tick中最大缓冲，默认最小风险距离2。老师明确SL优先；结构需要超过默认10价格距离时不硬缩止损下单。|
|总风险|按账户货币计算开仓至SL的损失，候选单不超过一份“0.02手×保险距离”的标准单风险；合计默认不超过两份。盈利仓不抵扣其他单风险，无SL仓位阻止叠加。限额是提交前估算，不覆盖跳空、滑点和费用。|
|分级保护|R=实际成交价到冻结初始SL的价格距离。观察到浮盈0.5R后把剩余初始风险减至0.5R；1R或真实成交已减半后移至开仓价加0.20有利方向缓冲。SL只收紧。|
|首批止盈|默认取5、max(2,0.8R)、下一参考点位前空间的最小值；近障碍作为全量TP时首批置于该目标距离70%处。老师明确首批价优先。到价请求减至初始量一半；不要求所有K线同色。|
|尾仓|顺势默认目标max(原尾仓距离,2R)；非顺势另受下一参考点位约束。老师明确TP优先。减半实际成交后，以持仓后形成的最近3根完整M1低/高点加缓冲跟踪SL。|
|结构/时间退出|M1收盘破入场结构则申请退出；默认8分钟仍未达到0.35R浮盈且当前不盈利则申请退出。单根普通反向K不构成退出条件。回撤越过已获得保护位时申请退出，不退回原SL。|

消息保护使用MT5原生美元高重要性日历：就业、价格、货币政策类别默认事件前后各10分钟暂停新单，其他高重要性事件前后各3分钟；重点事件前2分钟起主动退出**新策略持仓**，该参数设0可关闭主动消息退出。事件窗口结束后3分钟转M1确认。日历读取失败不清掉已知事件，超过180秒未成功更新则暂停新单；既有持仓管理仍运行。关闭“启用消息日历”会同时关闭这两项日历保护。

异常冲击包括快速单向运动、当前分钟显著扩张和异常点差：默认冷却120秒，之后180秒要求窗口结束后形成的M1确认。冲击持续则延后冷却，微小回拉不清零；冷却及恢复期限跨重启保存。这只依据已发生的报价，不能提前识别突发新闻。日历依据[官方文档](https://www.mql5.com/en/docs/calendar/calendarvaluehistory)使用券商服务器时间，无需手工转换北京时间。

新策略开关只影响后续开仓。升级前的旧单保持原退出逻辑；已经按新策略成交的单子即使关闭开关也继续新策略管理。入场SL、首批、TP、结构及R按真实成交持久化；同一老师计划后续明确更新仍可生效，但SL不会放宽。保护比例、缓冲、时间退出及消息参数属于当前运行参数，重新加载修改后会作用于已有新策略单。观察模式仍暂停自动交易和管理，不要用它代替消息保护。

持仓页显示R、定时管理采样所得最大浮盈及实际SL保护状态，请求中显示“待确认”；约每秒管理一次，并非逐tick最大浮盈统计。日志记录入场路径、结构风险、M1 ATR、首批目标、退出原因和请求对账。分批量始终依据实际Deal，不凭发送结果或按钮状态推断。

## 入场

每根新收完的M1完成评估一次，方向确认使用已收盘K线。报价、K线或指标暂未就绪时按秒重试同一根，仍受原来的K线开盘后90秒窗口约束（正常收盘后约30秒）；超过窗口、策略条件不成立或已发请求都不补单。发送前重新检查报价、点差、权限、手数、保护价和保证金。

|方法|条件|
|---|---|
|M5 MA5顺势回踩|SMA5斜率同向，上一根M5整根脱离，最新收盘守同侧；M1同时靠近均线和点位。最近六次均线换边达三次，不使用趋势入口。|
|M5突破回测|从点位另一侧到收盘突破，再到下一根M5回踩守住，随后M1继续确认。|
|震荡点位反应|没有清晰MA趋势，最新M5收盘在计划持有侧、没有超过2ATR的大波动，点位附近出现完整M1止跌或受阻。|

M1统一要求：最近两根之一靠近点位，后一根不继续刷新低点/高点，按预期方向收线并收回点位。清晰相反M5趋势时不逆势强做。

附近范围为 max(0.2ATR,2tick)，收回幅度为 max(0.05ATR,1tick)，追价不超过 min(0.75ATR,首批目标的80%)。这些阈值与SMA选择属于工程定义，不是T哥逐项给出的公式。

每次接触只消费一次请求机会，包括明确拒绝。完整M1离开超过 max(ATR,2价格单位) 后重新回踩才可再试；重启或消息重发不能直接清掉消费记录。没有每点位每天两次的额外上限，也不亏损加倍。

最近七根M5里反复穿越点位达三次时，停用普通反应；明确突破回测仍可转换支撑/阻力角色。这是结构过滤，不是按点位年龄过期。

## 保险、分批和尾仓

全部“点”指黄金报价的价格距离，例如4140到4130为10，不是10个_Point。

- 默认初始保险10，以实际开仓价核对，不放宽已有更保护的SL。
- 正常0.02手到盈利5时请求减0.01。真实退出Deal确认后，余仓SL移到开仓价。
- 尾仓目标最多10；下一点位更近则设在该点位之前 max(0.20,2tick)。空间不足以先收5点时不入场。
- 券商规格无法拆分时，全量服务器TP改为5，不把剩余0.01误当成待分批的新仓。
- 保本指开仓价格，不保证费用后的净盈亏为零。快速跳价可能直接触及服务器TP而来不及分批；断线不能执行本地分批。
- 修改输入会影响后续管理计算。有本EA持仓时避免更改保险/首批规则；代码不会放宽已有保护性SL。

T哥有10点保险、5点起步收米和分成两份留仓的原话，也出现过临时5点、15点保险等场景。固定0.02、5点收半、余仓价格保本、10点尾仓，是常用原则结合本次要求的实现，不能声称覆盖他每条临时指令。本版尚未从自由聊天自动提取逐单临时SL/TP覆盖。

## 请求与重启

请求前保存pending，以真实Order、Deal、POSITION_IDENTIFIER及持仓确认；CTrade返回true不等于完成。分批量按入/出Deal累计恢复，重启后不会重复减仓，退出归属不只看退出Magic。

超时不会自动当失败重发。30秒仍无法唯一对账时显示待核对并停止新请求；未知请求或持久化写入中断需核对专家日志、券商历史，不能盲删全局变量解锁。单机独占锁防同账户/品种/Magic重复实例，未验证多机并发。

默认每日权益回撤1%，以当日首次运行看到的账户权益为基准，包含账户其他交易。触发后当天停止新单，继续管理原仓；不是保证最大亏损1%的强制平仓器。中途首次启用不声称恢复此前全天权益。

- 两组独立使用0.02手、固定TP5/SL10、最长60分钟退出、相同持仓上限、点差/消息/冲击门槛和费用设置。
- A组是“碰价基准”，不等同于完整复刻旧EA：不读取真实单的消费记录、持仓数量或连亏结果；两组均使用模拟区域去重及离开4点至少5秒后再入。
- “观察模式”下两组仍自动运行；“交易模式”下原EA仍可能下真实单。模拟不接管、拦截、平仓或修改实盘订单。

### 实盘参数与兼容性

新增“入场策略”：默认“兼容原设置”，保持此前随持单策略选择入场检查的行为。另可明确选择“原触价检查”或“原行情/消息保护检查”，它们与持单策略独立。该选项尚不包含把新研判用于实盘。持单策略继续只决定新开仓采用的退出方式，已有仓位遵循原记录。

模拟开关、每手往返费用（账户货币/手）、单边不利滑点（价格差）可在EA参数配置。费用0会明确显示“尚未配置”，金额不能当作已扣佣金的净收益。计算采用实际采样Bid/Ask，已包含点差，另扣配置费用和进出滑点；不含隔夜费。

### 成绩与记录

页面显示两组尝试次数、完成/进行中数量、盈利/亏损笔数、累计模拟结果、已实现最大回撤，以及因缺失过程而排除的数量。等待原因和最近结束结果自动更新。无需人工判读K线才能继续运行。

账本位于 MT5 Common/Files/FeishuMT5SignalMonitor/paper/，按账户、服务器、品种、Magic和比较参数分开。更改比较参数或费用会切换账本，避免不同假设混算。OPEN/CLOSE记录保存消息来源、方向、价格、时间、判断K线、费用、持仓期间采样的最大顺行/逆行；临近点位的WAIT原因每组每分钟最多记录一次。原始K线判断快照仍在observations目录。

写入成功才推进模拟事件；失败冻结同一事件并暂停新模拟、定时重试。序号和内容校验用于恢复和去重；完整记录校验失败时停止模拟、保留原文件。重启时恢复完成成绩；未结束模拟单因离线过程未知标记“不完整”，不猜测止盈或止损。运行期间报价相隔超过5秒，同样排除跨缺口持仓。持仓即使遇到消息取消或同步中断也继续按有效报价模拟退出。

### 本版的验证边界

模拟每秒采样一次，可能漏掉秒内触价；不是逐tick回测，也不等于券商成交。止盈不额外获得跳空收益，止损按更差采样价计算。收益由OrderCalcProfit换算为账户货币；换算失败不伪造结果。未结束仓位浮盈不计入已实现成绩，盈亏相等的单子计完成但不计赢/亏。

本版用于自动积累两组可比较记录，尚不宣称哪组更优，也不自动修改策略参数或开启实盘。仍需连续运行数据及模拟账户执行验证后，才能决定是否让新研判接管真实下单。


## v1.72：自动保存历史证据与五组研判试做（2026-10-16）

这版把“群消息当时说了什么、EA当时知道什么、行情后来怎么走”分开保存，专门为后续复盘和历史模拟准备。保存不会回填过去的点位：新点位只有在 EA 实际收到之后形成的新 K 线里才有资格触发，防止回测偷看未来消息。

### 研判页面的五组策略

打开“研判”页后，五组会同时运行。点击某一组只改变下方明细，不会停掉其他组；每组都有自己的模拟账本、持仓上限、去重和重启恢复记录。

| 组别 | 简单理解 | 入场依据 |
| --- | --- | --- |
| A 碰价基准 | 原来的基准组 | 价格进入有效点位附近就记录一次模拟入场，保留消息原方向 |
| B 区间反弹 | 原观察组 | 已收盘K线在点位附近出现收回，且消息方向与行情没有冲突 |
| C 单点收回 | 只看这一个点位 | 先看已完成K线是否从点位另一侧收回，不要求均线趋势 |
| D 顺势回踩 | 收回后还要顺着趋势 | C组条件成立，并且缓存的M5趋势方向一致 |
| E 突破回踩 | 突破后回踩确认 | 先有一根完整K线收盘突破，再由下一根完整K线回踩并站回，不用同一根K线的最高/最低价猜先后 |

五组都使用当前模拟参数：默认每次0.02手、固定TP5/SL10、最长60分钟、实际Bid/Ask采样、费用/滑点配置、消息窗口和行情断线门禁。它们是可比较的“假设组”，不是盈利保证；A组和旧EA的真实入场也不是同一条执行链。模拟只写入研判账本，不接管真实订单，不平仓、不改单，也不会因为成绩好就自动切换实盘策略。

策略采用了常见的支撑阻力、突破后角色转换和回踩确认思路，但这里只把它们做成可观察的实验规则。支撑阻力和突破后的角色转换可参考CME Group技术分析说明：https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance 。五组结果仍需积累真实样本后再评价，不能把单日成绩当成结论。

### 保存了什么

监控端的 SQLite 位于：

%LOCALAPPDATA%/FeishuMT5SignalMonitor/data/monitor.sqlite

新增三类历史：

- message_versions：每次消息版本的原文、消息发布时间、EA/监控收到时间、是否历史导入、是否升级前基线。消息编辑、撤回、A→B→A都会保留，重复心跳不重复写。
- point_state_versions：老师点位、场景、DeepSeek研判、网页手动点位的完整状态变化。相同状态不重复写，事务失败会一起回滚。
- execution_versions：每次真正改变点位出口内容的TGA9完整快照。只改生成时间或心跳不会制造假版本，清空、撤销和恢复都会留下版本。

EA端的行情证据位于 MT5 公共目录：

Common/Files/FeishuMT5SignalMonitor/replay/YYYYMMDD/

每次挂载会生成一个会话TSV，记录：

- EA实际收到的报价，以及报价之间超过5秒的断流标记；
- EA看到的已收盘M1 K线；
- EA接受过的TGA9点位快照；
- 点位版本的本地可用时间、消息/冲击暂停、恢复状态和五组模拟策略版本；
- 会话开始、结束和缓冲溢出标记。

这里保存的是 EA 回调期间实际收到的报价，不是向券商补拉的完整逐笔历史。重启、断线、缓冲溢出和缺少完整收盘K线都会明确写成缺口；后续回放遇到缺口时必须排除跨缺口的结果，不能补造一条“看起来连续”的行情。MQL5 的历史报价接口本身也可能只返回部分数据或因超时失败，因此本版选择保留现场收到的证据并标明覆盖范围，避免把补拉数据冒充实时现场。

### 日常查看

1. 监控重启后，等待监控状态恢复正常；历史表会自动创建。
2. 重新挂载新版 EA_T哥点位跟单.ex5，输入参数中“历史归档”默认开启。
3. 在“研判”页观察五组各自的完成数、胜负、累计结果、回撤和排除数。
4. 点击策略名称查看该组最近一次等待/入场/平仓原因。切换按钮只是查看，不会改变正在运行的组。
5. 连续运行一段时间后，再按同一消息版本、同一策略规则和同一行情缺口规则做回放比较。

本版只建立证据和对比基础，暂未加入离线回放引擎，也不会根据五组成绩自动改参数或开放真实新策略。EA 重新编译结果为0 errors、0 warnings；纸面策略、归档格式和监控SQLite回归均使用合成数据验证，未执行券商交易。
